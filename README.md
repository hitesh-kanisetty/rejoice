# Employee Management Dashboard

A simple React.js Employee Management Dashboard developed as part of a technical evaluation.

## 👨‍💻 Developer

**Hitesh Kanisetty**

GitHub: https://github.com/HiteshKanisetty

## 📌 Project Overview

This application allows users to manage employee information through a simple and responsive dashboard.

The application includes:

- View employee details
- Search employees by name or email
- Filter employees by Active/Inactive status
- Add new employees
- Basic form validation
- Delete employees
- Responsive design

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## ✨ Features

### Employee List

Displays:

- Name
- Email
- Role
- Status
- Delete action

### Search

Employees can be searched using their:

- Name
- Email

### Add Employee

Users can add a new employee by providing:

- Name
- Email
- Role
- Status

Basic validation is included to ensure the required fields are filled.

### Status Filter

Employees can be filtered by:

- All
- Active
- Inactive

### Delete Employee

Employees can be removed from the list without refreshing the page.

## ⚛️ React Concepts Used

- Functional Components
- `useState`
- Props
- Event Handling
- Array methods such as `map()` and `filter()`
- Conditional Rendering
